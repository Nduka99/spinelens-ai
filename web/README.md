# Innovation Spine Web App

This is the production web workspace for the next presentation phase.

Source of truth: `../webapp_implementation_plan.md`.

The app direction is:

- Vite + React + TypeScript;
- static hosting only, with no runtime API requirement;
- sanitized public content generated by `build_content.py`;
- MapLibre/deck.gl scrollytelling with Journey and Explore modes;
- local UX, responsive, accessibility, E2E, and performance checks before deployment;
- zero ongoing hosting cost on Cloudflare Pages or Vercel.

## Prep Commands

From the repository root:

```powershell
.\.bkqproj\Scripts\python.exe web\build_content.py --check
.\.bkqproj\Scripts\python.exe -m pytest
.\.bkqproj\Scripts\python.exe -m ruff check phase1_spinelens_ai/src phase1_spinelens_ai/tests
```

JavaScript toolchain status:

- Node: `v24.14.1`
- npm: `11.11.0`
- npx: `11.11.0`
- corepack: `0.34.6`

On Windows automation, invoke npm through the shell shim, e.g. `cmd /c npm --version`, because
some non-shell child-process runners do not resolve `npm.cmd` automatically. In PowerShell or a
normal terminal, `npm` works directly.

From `web/`, the current prep check is:

```powershell
npm run content:check
```

The next implementation step can safely scaffold/install Vite dependencies with npm when we are
ready to create the actual app.
